# SEO Northstar logo — source & rebuild

Everything in `/assets/logo/`, the favicons (`/favicon*.png`, `/favicon.svg`, `/favicon.ico`,
`/apple-touch-icon.png`), `/og-image.png` and `/assets/logo-*.png` is generated by these scripts.
Folders starting with `_` are not published by GitHub Pages.

## Spec (Round 5, approved 18 Nov 2026)
- Wordmark: "SEO Northstar", Space Grotesk Bold (700), tracking −0.01em, HarfBuzz kerning.
- Pin height = cap height (700/1000) + the font's own overshoot: round head +14/1000 above the cap line
  (same as "O"), pointed tip +21/1000 below the baseline.
- Pin → text gap = the font's word space (same as the gap between "SEO" and "Northstar").
- Pin: head radius r, tip 1.9r below centre. Upright symmetric 4-point star centred on the head centre,
  outer radius 0.58r, inner radius 0.30 × outer.
- Colours: navy #0F1B2D, gold #E8B54D, off-white #F6F4EF. No gradients/shadows.
- Clear space: one cap height on every side. Favicon: navy pin, off-white star, gold tile.

## Rebuild (all open source)
```
pip install fonttools brotli uharfbuzz pillow ; npm i -g svgo ; apt install librsvg2-bin
mkdir fonts && python3 - <<'PY'
from fontTools.ttLib import TTFont; from fontTools.varLib import instancer
for name,src,w in [('sg-400','space-grotesk-var.woff2',400),('sg-500','space-grotesk-var.woff2',500),
                   ('sg-700','space-grotesk-var.woff2',700),('inter-500','inter-var.woff2',500)]:
    f=instancer.instantiateVariableFont(TTFont('../'+src),{'wght':w}); f.flavor=None; f.save(f'fonts/{name}.ttf')
PY
python3 build_final.py ..
```
